DM Mono uppercase eyebrow/label. Use `framed` for the chamfered pill treatment seen above headlines and on nav tags.

```jsx
<Eyebrow>Positioning statement</Eyebrow>
<Eyebrow framed>Eyebrow text</Eyebrow>
<Eyebrow tone="light" framed>All condition intelligence</Eyebrow>
```

Set `tone="light"` on dark backgrounds.
