Chamfered DM Mono button — the primary Loop X call to action ("MORE INFO", "> KNOW MORE"). Use `arrow` for forward actions.

```jsx
<Button arrow>More info</Button>
<Button variant="solid" tone="light">Get started</Button>
<Button size="sm" variant="ghost">Read</Button>
```

Variants: `outline` (default), `solid`, `ghost`. Set `tone="light"` on dark backgrounds. The cut-corner silhouette comes from `.lx-chamfer` and is core to the brand — keep it.
