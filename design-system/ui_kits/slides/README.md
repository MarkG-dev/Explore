# Loop X — Presentation slides

Sample slide layouts extending the Loop X system to decks. Each `.slide.html` is a self-contained 1280×720 frame composing design-system components (`Logo`, `PageHeader`, `Eyebrow`).

- **title.slide.html** — black ground, oversized wordmark, presentation headline.
- **content.slide.html** — light ground: framed eyebrow, headline, body + chamfered image.
- **agenda.slide.html** — grey ground, numbered index list.
- **chapter.slide.html** — black ground, terrain photo, numbered chapter title.
- **threeup.slide.html** — light ground, three captioned monochrome images.

Two grounds only per deck (black / off-white, with grey for agendas). Headlines uppercase Aeonik; labels DM Mono; imagery monochrome and high-contrast.
