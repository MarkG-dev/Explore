# Loop X — Website UI kit

Interactive recreation of the Loop X marketing site, built from the design-system components.

- **index.html** — mount + interactive nav (HOME / PLATFORM / ABOUT / SOLUTIONS).
- **screens.jsx** — `Hero`, `Products`, `About` screens exposed on `window.LoopXSite`.

Composes `Navbar`, `Button`, `ProductCard`, `Eyebrow` and `Logo` from `window.DesignSystem_d0e166`. Photography lives in `assets/img/` (monochrome, high-contrast). The hero is dark with a full-bleed terrain image, oversized wordmark, and the "ALL CONDITION INTELLIGENCE" headline; the platform view is a light grid of product cards.
